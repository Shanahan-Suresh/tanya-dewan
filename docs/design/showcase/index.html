How these were made

A shared brief fixed the content and the rules for all three: real records only, every AI-written line labelled, the unrevised-draft mark as an icon with coloured text, phone width and dark mode designed. Each design was then built by its own agent as plain HTML and CSS, so whichever you pick moves straight into the site's templates.

The answer on each Ask page is one real answer from the site, about targeted diesel subsidies. Every example question replays that same answer. The debate is item 17 of the 22 October 2026 sitting, which is still an unrevised draft. That debate belongs to no bill, so each design shows the Employment (Amendment) 2021 bill as its sample timeline.

Each design follows your device's light or dark setting. The pictures include a dark version of each Ask page.
