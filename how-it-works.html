Gather

Acts

  • 66,052 sections, in Malay and English.
  • Scanned pages go through OCR, then a text check.

The code

parlimen/acts.pyparlimen/act_text.pyparlimen/act_ocr.py

Gather

Hansard

  • Each file is fetched once and cached, with a polite rate limit.
  • Draft sittings are checked each week until the final copy appears.

The code

parlimen/fetch.pyparlimen/sittings.pyparlimen/drafts.py

Understand

Parse who spoke

  • The parser reads speaker lines, seats and times from the PDF text.
  • It links each speaker to one of 341 MPs and their party on that date.

The code

parlimen/hansard.pyparlimen/parties.pyparlimen/links.py

Understand

Enrich Uses Claude

  • 31,767 questions joined to the minister's answer.
  • A summary and topic tags for each debate.
  • A commitment is dropped when its quote is not in the Hansard text.

The code

parlimen/enrich.pyparlimen/commit_check.py

Find

Keyword index

  • Finds exact words, names and section numbers.
  • Malay and English in one index.

The code

parlimen/index.pyparlimen/chunk.py

Find

Meaning index

  • Finds passages that say the same thing in other words.
  • It runs on a CPU at search time.

The code

parlimen/index.pyparlimen/models.py

Find

Merge and rerank Uses Claude

  • Reciprocal rank fusion merges the two lists.
  • Claude Haiku reads the top 20 and keeps the best 8.

The code

parlimen/search.pyparlimen/llm_rerank.py

Answer

Write the answer Uses Claude

  • Each sentence must cite a quoted passage.
  • It refuses advice on a reader's own case.
  • The text streams to the page as server-sent events.

The code

parlimen/answer.pyparlimen/web/app.py
